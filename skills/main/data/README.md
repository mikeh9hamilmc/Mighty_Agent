# Main Agent Data Folder

Place general reference documents here for the Main Agent to consult.

These are documents the main agent can read directly before deciding to answer or route to a sub-agent.

Examples:
- Personal notes or preferences
- General instructions for the agent
- Reference documents that don't belong to legal, medical, or finance

Supported file types: `.pdf`, `.docx`, `.doc`, `.xlsx`, `.xls`, `.txt`, `.md`
