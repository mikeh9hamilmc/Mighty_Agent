# Legal Documents Folder

Drop your PDF, DOCX, XLSX, TXT, or Markdown files here.

Then tell the agent: **"ask legal read documents"**

The agent will parse, chunk, and embed every file using Voyage AI's `voyage-law-2` model.
The index is saved to `.rag-index.json` in this folder and persists across restarts.

## Supported file types
- `.pdf`
- `.docx` / `.doc`
- `.xlsx` / `.xls`
- `.txt`
- `.md`
