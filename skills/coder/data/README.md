# Coder Agent — Reference Documents

Place any files you want the Coder sub-agent to reference here:

- **API documentation** (`.txt`, `.md`, `.pdf`) — e.g. Interactive Brokers API docs
- **Example scripts** — reference Python code the agent can learn from
- **Requirements files** — e.g. `requirements.txt` snippets for specific libraries
- **Architecture notes** — descriptions of patterns you want the agent to follow

Files placed here will be automatically indexed and searchable by the Coder agent
via `list_documents`, `grep_documents`, and `view_document` tools.
