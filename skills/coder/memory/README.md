# Coder Agent Memory

This folder stores the Coder sub-agent's persistent long-term memory.

Files are automatically created by the agent using the `save_memory` tool.

Example memory topics:
- `ib-api-pattern.md` — notes on Interactive Brokers ib_insync patterns
- `skill-template.md` — preferred skill boilerplate
- `user-preferences.md` — coding style preferences from the user
